# Slop Detector

Slop Detector is a POC menu bar app for macOS. 

Its very simple, you can highlight text anywhere on your machine and key **⌘⇧D** to get an estimate if the text is generated by AI.

The model runs locally on your machine and is a combination neural net and heuristic ruleset. The neural net comes from an open source HuggingFace model, while the heuristics are based on a number of open source rulesets.

## Install

```bash
git clone https://github.com/snowpackdata/slop-detector.git
cd slop-detector
make install
```

Open the app from Spotlight or `/Applications`. The app will be available in your menu bar as `slop`.

Requires macOS 13+ and Xcode CLI tools (`xcode-select --install`). 

The first use will request Accessibility permission to grab selections from your screen as well as notifications for updates.


**Neural model** — a DistilBERT classifier fine-tuned on AI vs. human text (99.74% accuracy on its eval set).

**Heuristic rules** — pattern matching for clear cut patterns with explainable outputs:

- Invisible Unicode (zero-width spaces, BOM, directional overrides)
- AI punctuation (em dashes, curly quotes, horizontal ellipsis)
- ~90 LLM phrases ("delve", "it's worth noting", "navigate the complexities")
- Statistical signals (sentence length uniformity, vocabulary repetition, hedge word density)
- Grammar tells (dropped subjects, passive voice, tool personification — "Fivetran has the headline")
- Watermarks (Cyrillic homoglyphs, variation selectors)

The UI popover shows the overall percentage of AI content, per-paragraph breakdown, and heuristic flags.

## Updating

The app checks GitHub for new releases on launch. You can also click `slop` in the menu bar → **Check for Updates**. When there's a new version:

```bash
cd slop-detector
git pull
make install
```

## Build targets

```
make build      # compile the binary
make setup      # download the neural model (117 MB, one-time)
make app        # compile + package Slop Detector.app
make install    # all of the above + copy to /Applications
make run        # compile + run from terminal
make clean      # delete everything generated
```
